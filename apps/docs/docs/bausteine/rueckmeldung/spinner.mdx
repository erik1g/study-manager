# Spinner

```jsx live

  <Spinner />

  <span style={{ display: "inline-flex", gap: 8, alignItems: "center", color: "var(--ui-muted)" }}>
    <Spinner size={16} label="" /> Wird transkribiert …
  </span>
</div>
```

## Wann benutzen

- Für Wartezeiten unbekannter Länge, die länger als einen Moment dauern.
- In Knöpfen nicht selbst einbauen – `loading` am [Button](../aktionen/button).
- Ganze Seiten: `PageSkeleton`. Bekannter Fortschritt: [ProgressRing](../anzeige/progress-ring).
