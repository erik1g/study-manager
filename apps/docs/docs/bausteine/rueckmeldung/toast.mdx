# Toast

`import { toast, Toaster } from "@study/ui"`

```jsx live
<div style={{ display: "flex", gap: 10, flexWrap: "wrap" }}>
  <Button onClick={() => toast("Gespeichert")}>Neutral</Button>
  <Button onClick={() => toast("Link kopiert", "success")}>Erfolg</Button>
  <Button onClick={() => toast("Keine Verbindung", "danger")}>Fehler</Button>
  <Toaster />
</div>
```

`<Toaster />` steht einmal in der App; `toast(text, tone?)` geht von überall.

## Wann benutzen

- Bestätigungen, die man nicht lesen muss: „Gespeichert“, „Kopiert“, „In den Papierkorb gelegt“.
- Nichts, worauf man reagieren muss – dafür [Notice](./notice) oder ein Dialog.
- Höchstens ein Satz.

## Barrierefreiheit

- Der Toaster ist ein `aria-live="polite"`-Bereich: Screenreader lesen die Meldung, ohne zu unterbrechen.
- Er bleibt 2,8 Sekunden – lang genug zum Lesen, nicht so lang, dass er stört.
