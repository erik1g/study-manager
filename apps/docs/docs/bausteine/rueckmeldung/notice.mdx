# Notice

`import { Notice } from "@study/ui"`

```jsx live
<Notice tone="danger" title="Hochladen fehlgeschlagen" action={<Button size="sm">Erneut versuchen</Button>}>
  Kapitel 4.pdf ist größer als 95 MB.
</Notice>
```

## Varianten und Zustände

<Preview column>
  <Notice tone="info">Claude kann Fristen und Aufgaben für dich anlegen.</Notice>
  <Notice tone="success" title="Verbunden">Dein Kalender wird stündlich abgeglichen.</Notice>
  <Notice tone="warning">Der Schlüssel läuft in 5 Tagen ab.</Notice>
  <Notice tone="danger">Falsches Passwort.</Notice>
</Preview>

## Wann benutzen

- Was man lesen **muss** oder das bleibt: Fehler beim Speichern, ein ablaufender Schlüssel, eine Erklärung.
- Kurze Bestätigungen wie „Gespeichert“: [Toast](./toast).
- Fehler zu einem Feld: `error` am Feld, nicht hier.

## Barrierefreiheit

- `danger` ist `role="alert"` und wird sofort vorgelesen; alle anderen sind `status`.
- Icon **und** Text tragen die Bedeutung, nicht nur die Farbe.
