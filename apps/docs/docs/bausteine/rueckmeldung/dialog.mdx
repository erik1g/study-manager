# Dialog und ConfirmDialog

`import { Dialog, ConfirmDialog } from "@study/ui"`

Ein Dialog ist sichtbar, solange er gerendert wird; `onClose` entfernt ihn.

```jsx live
function Beispiel() {
  const [open, setOpen] = useState(null);
  return (
    <div style={{ display: "flex", gap: 10 }}>
      <Button variant="primary" icon="plus" onClick={() => setOpen("new")}>Fach anlegen</Button>
      <Button variant="danger" icon="trash" onClick={() => setOpen("delete")}>Fach löschen</Button>
      {open === "new" && (
        <Dialog title="Neues Fach" onClose={() => setOpen(null)}
          footer={<><Button onClick={() => setOpen(null)}>Abbrechen</Button><Button variant="primary" onClick={() => setOpen(null)}>Anlegen</Button></>}>
          <TextField label="Name" placeholder="z. B. Regelungstechnik" autoFocus />
        </Dialog>
      )}
      {open === "delete" && (
        <ConfirmDialog title="Regelungstechnik löschen?" confirm="Löschen" danger onClose={() => setOpen(null)}
          onConfirm={() => new Promise((r) => setTimeout(r, 800))}>
          Dateien, Notizen und Lernkarten des Fachs liegen dann 30 Tage im Papierkorb.
        </ConfirmDialog>
      )}
    </div>
  );
}
```

## Wann benutzen

<DoDont>

  </Do>
  <Dont caption="Lange Formulare oder Dialoge in Dialogen – dafür eine eigene Seite.">
    <Button>Alle Einstellungen bearbeiten …</Button>
  </Dont>
</DoDont>

- Unten rechts: zuerst Abbrechen, zuletzt die Hauptaktion.
- `ConfirmDialog` vor allem, was sich nicht leicht rückgängig machen lässt; sein `onConfirm` darf ein Promise sein – der Knopf lädt, ein Fehler erscheint im Dialog.
- Mehr unter [Muster › Löschen bestätigen](/muster/loeschen-bestaetigen).

## Barrierefreiheit

- Ein echtes `<dialog>` als Modal: Der Rest der Seite ist gesperrt, der Fokus bleibt drin.
- Titel und Beschreibung sind mit `aria-labelledby`/`aria-describedby` verbunden.
- Escape und das × schließen; danach kehrt der Fokus zum auslösenden Knopf zurück.
- Im `ConfirmDialog` hat „Abbrechen“ den Fokus – Enter richtet keinen Schaden an.
