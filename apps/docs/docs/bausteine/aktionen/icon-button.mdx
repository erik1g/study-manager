# IconButton

`import { IconButton } from "@study/ui"`

Für Werkzeugleisten, das ⋯ einer Karte, Schließen-Kreuze. Der `label` ist **Pflicht**: Er ist der Name für Screenreader und erscheint als Tooltip.

```jsx live
function Beispiel() {
  const [pinned, setPinned] = useState(false);
  return (
    <div style={{ display: "flex", gap: 8 }}>
      <IconButton icon="more" label="Weitere Aktionen" />
      <IconButton icon="star" label="Anheften" pressed={pinned} onClick={() => setPinned(!pinned)} />
      <IconButton icon="close" label="Schließen" variant="secondary" />
    </div>
  );
}
```

## Wann benutzen

<DoDont>
  <Do caption="Bekannte Zeichen, wo wenig Platz ist: ⋯, ×, Stift.">
    <IconButton icon="more" label="Weitere Aktionen" />
    <IconButton icon="close" label="Schließen" />
  </Do>
  <Dont caption="Eine wichtige Aktion nur als Icon – lieber ein Button mit Text.">
    <IconButton icon="upload" label="Hochladen" variant="primary" />
  </Dont>
</DoDont>

- Löschen nie als einzelner IconButton ohne Rückfrage – lieber im Menü hinter ⋯ mit [ConfirmDialog](../rueckmeldung/dialog).
- `pressed` für Schalter wie „anheften“; der Zustand wird dann vorgelesen.
- `badge` zeigt eine kleine Zahl, etwa ungelesene Benachrichtigungen; bei 0 verschwindet sie. Screenreader hören sie mit dem Namen („Benachrichtigungen (3)“).

## Barrierefreiheit

- `label` wird zu `aria-label` und `title`; das Icon selbst ist versteckt.
- `pressed` setzt `aria-pressed`.
- Auch in `sm` 36 px groß; `md` erfüllt 44 px.
