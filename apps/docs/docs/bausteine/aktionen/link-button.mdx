# LinkButton

`import { LinkButton } from "@study/ui"`

Ein Link im Kleid eines Knopfs: „Jetzt lernen“, „Alle Dokumente“, „Zur Anmeldung“. Er navigiert – für Aktionen ist [Button](./button) da.

```jsx live
<div style={{ display: "flex", gap: 10, flexWrap: "wrap" }}>
  <LinkButton href="#" variant="primary" iconEnd="arrow-right">Jetzt lernen</LinkButton>
  <LinkButton href="#">Alle Dokumente</LinkButton>
</div>
```

In der App mit dem Router:

```tsx
import { Link } from "react-router";

<LinkButton as={Link} to="/faecher" variant="secondary">Alle Fächer</LinkButton>
```

## Varianten und Zustände

Dieselben wie beim [Button](./button), ohne `loading`.

## Barrierefreiheit

- Bleibt ein Link: Screenreader sagen „Link“, Strg-Klick öffnet einen neuen Tab.
- Externe Links mit `target="_blank"` bekommen `rel="noreferrer"` und das Icon `external`.
