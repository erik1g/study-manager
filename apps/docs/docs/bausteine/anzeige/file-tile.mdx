# FileTile

`import { FileTile, fileKind } from "@study/ui"`

```jsx live
<List style={{ maxWidth: 480 }}>
  {["Skript Kapitel 4.pdf", "Formelsammlung.docx", "Vorlesung 27. Okt.m4a", "Tafelbild.jpg"].map((name) => (
    <ListRow key={name} leading={<FileTile kind={fileKind(name)} />} title={name} meta="Skripte · heute" />
  ))}
</List>
```

## Varianten und Zustände

<Preview>
  <FileTile kind="pdf" /><FileTile kind="word" /><FileTile kind="slides" /><FileTile kind="sheet" />

`fileKind(name, mime?)` bestimmt die Art aus Endung oder MIME-Typ.
