# Avatar und AvatarGroup

`import { Avatar, AvatarGroup } from "@study/ui"`

Ohne Bild zeigt der Avatar die Initialen in der Farbe der Person – überall dieselbe, weil sie aus der Id (`colorKey`) berechnet wird.

```jsx live
<div style={{ display: "flex", gap: 16, alignItems: "center" }}>
  <Avatar name="Mira Hansen" size={48} />
  <AvatarGroup label="4 Mitglieder">
    <Avatar name="Mira Hansen" colorKey="u1" decorative />
    <Avatar name="Jonas Weber" colorKey="u2" decorative />
    <Avatar name="Sina Ok" colorKey="u3" decorative />
    <Avatar name="Tom Berg" colorKey="u4" decorative />
  </AvatarGroup>
</div>
```

## Wann benutzen

- Neben einem Namen: `decorative`, damit der Name nicht doppelt vorgelesen wird.
- In der App reicht das Bild-`src` von `/api/avatars/<id>?v=<version>`; fehlt es oder lädt es nicht, erscheinen die Initialen.
- Gelöschte Konten: `gone` – grau mit Strich.

## Barrierefreiheit

- Allein stehend ist der Avatar ein Bild mit dem Namen als Beschreibung.
- Eine Gruppe hat einen Namen („4 Mitglieder“); „+2“ steht als Text da.
