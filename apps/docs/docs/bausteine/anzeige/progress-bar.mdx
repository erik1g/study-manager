# ProgressBar

`import { ProgressBar } from "@study/ui"`

```jsx live
function Beispiel() {
  const [v, setV] = useState(0.35);
  return (
    <div className="ui-stack" style={{ maxWidth: 420 }}>
      <ProgressBar value={v} label="Wird transkribiert" tone="violett" />
      <Button size="sm" onClick={() => setV(Math.min(1, v + 0.15))}>Weiter</Button>
    </div>
  );
}
```

## Wann benutzen

- Für Arbeiten mit bekanntem Fortschritt, die Sekunden bis Minuten dauern: Hochladen, Transkribieren.
- Fortschritt eines Fachs: [ProgressRing](./progress-ring). Unbekannte Dauer: [Spinner](../rueckmeldung/spinner).
