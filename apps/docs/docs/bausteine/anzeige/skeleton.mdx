# Skeleton und PageSkeleton

`import { Skeleton, PageSkeleton } from "@study/ui"`

```jsx live
<div className="ui-stack">
  <div style={{ display: "flex", gap: 12, alignItems: "center" }}>
    <Skeleton shape="circle" width={40} />
    <div style={{ flex: 1 }}><Skeleton width="60%" /><Skeleton width="35%" height={12} /></div>
  </div>
  <PageSkeleton />
</div>
```

## Wann benutzen

- Eine Seite lädt das erste Mal: `PageSkeleton`.
- Ein Teil lädt nach: `Skeleton` in seiner Form.
- Kurze Wartezeiten nach einem Klick: `loading` am Button, kein Skeleton.

## Barrierefreiheit

- `PageSkeleton` sagt „Wird geladen“ (`role="status"`, `aria-busy`); einzelne Skeletons sind versteckt.
- Bei weniger Bewegung pulsiert nichts.
