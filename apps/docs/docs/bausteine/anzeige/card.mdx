# Card

`import { Card } from "@study/ui"`

Weiß mit weichem Schatten – oder in einer Fachfarbe. Große Karten oben auf einer Seite dürfen Verlauf (`glow`) und Korn (`grain`) tragen.

```jsx live
<div style={{ display: "grid", gap: 16, gridTemplateColumns: "repeat(auto-fit, minmax(240px, 1fr))" }}>
  <Card tone="blau" glow grain>
    <SectionHeader title="Heute" description="3 Termine" />
    <div style={{ width: 140, marginLeft: "auto" }}><Illustration kind="schreibtisch" /></div>
  </Card>
  <Card>
    <SectionHeader title="Zu erledigen" action={<Chip tone="gruen">1 von 4</Chip>} />
  </Card>
</div>
```

## Wann benutzen

<DoDont>
  <Do caption="Fachfarbe für Dinge eines Fachs; Weiß für Gemischtes.">
    <Card tone="blau" padding="sm">Regelungstechnik</Card>
    <Card padding="sm">Zu erledigen</Card>
  </Do>
  <Dont caption="Verlauf und Korn auf jeder Karte – dann ist nichts mehr besonders.">
    <Card tone="blau" glow grain padding="sm">A</Card>
    <Card tone="orange" glow grain padding="sm">B</Card>
    <Card tone="gelb" glow grain padding="sm">C</Card>
  </Dont>
</DoDont>

- Eine Karte, die woandershin führt: `as={Link}` und `interactive`. Dann darf in ihr nichts anderes klickbar sein – Aktionen (⋯) liegen daneben, nicht darin.
- Keine Karten in Karten in Karten. Innen: `variant="sunken"` oder eine [List](./list) mit `variant="raised"`.

## Props

Dazu alle Props des Elements aus `as`.

## Barrierefreiheit

- Wähle das passende Element: `section` mit Überschrift, `article`, `li` in Listen.
- Text auf Fachfarben nutzt immer `ink` – das stellt die Karte selbst ein.
