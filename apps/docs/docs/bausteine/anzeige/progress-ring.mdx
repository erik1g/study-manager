# ProgressRing

`import { ProgressRing } from "@study/ui"`

```jsx live
function Beispiel() {
  const [v, setV] = useState(0.62);
  return (
    <div style={{ display: "flex", gap: 20, alignItems: "center" }}>
      <ProgressRing value={v} label={`${Math.round(v * 100)} Prozent erledigt`} size={104} thickness={12} tone="petrol">
        <span style={{ fontSize: 24 }}>{Math.round(v * 100)} %</span>
      </ProgressRing>
      <input type="range" min="0" max="1" step="0.01" value={v} onChange={(e) => setV(+e.target.value)} aria-label="Wert" />
    </div>
  );
}
```

## Wann benutzen

- Fortschritt eines Fachs, einer Lernsitzung, eines Uploads mit bekannter Größe.
- Auf Fachfarben mit `onTint` – dann ist die Spur weiß.
- `animateKey`: Der Ring läuft beim ersten Erscheinen in einem Besuch hoch, danach steht er.
- Unbekannte Dauer? Dann [Spinner](../rueckmeldung/spinner).

## Barrierefreiheit

- Ein Bild mit `label` als Beschreibung – sag dort die Zahl in Worten („8 von 13 Kapiteln“).
- Die Farbe `strong` ist hell; die Zahl steht deshalb immer auch als Text daneben oder darin.
