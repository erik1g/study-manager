# List und ListRow

`import { List, ListRow } from "@study/ui"`

Eine Zeile hat vorne etwas (`leading`), einen Titel, eine leise zweite Zeile (`meta`) und hinten etwas (`trailing`). Mit `href` oder `onClick` wird die **ganze Zeile** Link oder Knopf.

```jsx live
<Card style={{ maxWidth: 520 }}>
  <List>
    <ListRow href="#" leading={<FileTile kind="pdf" />} title="Skript Kapitel 4 – Frequenzgang" meta="Skripte · 3,2 MB · heute" />
    <ListRow href="#" leading={<FileTile kind="word" />} title="Formelsammlung Laplace" meta="Sonstiges · 88 KB · Mo · Sina" />
    <ListRow leading={<FileTile kind="audio" />} title="Vorlesung 27. Okt." meta="84 Min. · transkribiert" trailing={<IconButton icon="more" label="Aktionen für Vorlesung 27. Okt." size="sm" />} />
  </List>
</Card>
```

## Wann benutzen

<DoDont>
  <Do caption="Entweder führt die ganze Zeile hin – oder sie ist kein Link und trägt Knöpfe.">
    <List style={{ width: "100%" }}>
      <ListRow href="#" title="Skript.pdf" meta="Skripte" />
      <ListRow title="Aufnahme 27. Okt." meta="wird transkribiert" trailing={<IconButton icon="close" label="Abbrechen" size="sm" />} />
    </List>
  </Do>
  <Dont caption="Ein Knopf in einer Zeile, die selbst ein Link ist: Wer ihn trifft, landet womöglich woanders.">
    <List style={{ width: "100%" }}><ListRow href="#" title="Skript.pdf" meta="Skripte" trailing={<span className="ui-button ui-button-ghost ui-size-sm ui-icon-button" aria-hidden="true">×</span>} /></List>
  </Dont>
</DoDont>

- `divided` auf weißen Karten, `raised` (weiße Pillen) auf Fachfarben.
- `ordered` für Reihenfolgen, z. B. Termine nach Uhrzeit.
- Mit dem Router: `linkAs={Link}` – `href` wird dann als `to` übergeben.

## Barrierefreiheit

- Echte `<ul>`/`<ol>` mit `<li>`: Screenreader sagen, wie viele Einträge es gibt.
- Eine Zeile ist entweder selbst klickbar oder enthält Klickbares – nie beides.
