# Switch

`import { Switch } from "@study/ui"`

```jsx live
function Beispiel() {
  const [on, setOn] = useState(true);
  return (
    <div style={{ maxWidth: 420 }}>
      <Switch label="Erinnerungen per E-Mail" description="Einen Tag vor jeder Frist." checked={on} onChange={(e) => setOn(e.target.checked)} />
    </div>
  );
}
```

## Barrierefreiheit

- Ein Kontrollkästchen mit `role="switch"`: Screenreader sagen „an“ oder „aus“.
- Grün heißt an – und der Knopf steht rechts. Beides zusammen, nicht die Farbe allein.
