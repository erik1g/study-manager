# SegmentedControl

`import { SegmentedControl } from "@study/ui"`

```jsx live
function Beispiel() {
  const [theme, setTheme] = useState("system");
  return (
    <SegmentedControl
      label="Darstellung"
      value={theme}
      onChange={setTheme}
      options={[
        { value: "light", label: "Hell", icon: "sun" },
        { value: "dark", label: "Dunkel", icon: "star" },
        { value: "system", label: "System", icon: "settings" },
      ]}
    />
  );
}
```

## Barrierefreiheit

- Echte Optionsfelder in einer `radiogroup`: Pfeiltasten wechseln, Tab springt hinein und hinaus.
- Mit `iconsOnly` bleiben die Namen für Screenreader und als Tooltip.
