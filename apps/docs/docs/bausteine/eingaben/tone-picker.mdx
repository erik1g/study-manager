# TonePicker

`import { TonePicker } from "@study/ui"`

```jsx live
function Beispiel() {
  const [tone, setTone] = useState("blau");
  return (
    <div className="ui-stack">
      <TonePicker label="Farbe des Fachs" value={tone} onChange={setTone} allowNone />
```

## Wann benutzen

- Für die Farbe eines Fachs – im Menü der Fachkarte und beim Anlegen.
- Nur die acht Fachfarben; eigene Farben gibt es nicht, damit alles zusammenpasst.

## Barrierefreiheit

- Echte Optionsfelder in einer `radiogroup`: Pfeiltasten wechseln, jede Farbe hat ihren Namen.
- Die gewählte Farbe hat einen Ring, nicht nur eine andere Farbe.
