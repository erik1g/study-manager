# Select

`import { Select } from "@study/ui"`

Eine Auswahl mit dem Auswahlfenster des Systems – auf dem Handy das Rad, am Rechner die Liste.

```jsx live
<div style={{ maxWidth: 360 }}>
  <Select label="Ordner" defaultValue="skripte" hint="Wohin die Datei kommt.">
    <option value="skripte">Skripte</option>
    <option value="uebungen">Übungen</option>
    <option value="klausuren">Klausuren</option>
    <option value="sonstiges">Sonstiges</option>
  </Select>
</div>
```

## Wann benutzen

<DoDont>
  <Do caption="Viele Möglichkeiten, eine davon gilt.">
    <Select label="Fach"><option>Regelungstechnik</option><option>Mathe III</option></Select>
  </Do>
  <Dont caption="Zwei bis vier Möglichkeiten – die gehören sichtbar nebeneinander.">
    <Select label="Darstellung"><option>Hell</option><option>Dunkel</option></Select>
  </Dont>
</DoDont>

Für zwei bis vier Möglichkeiten: [SegmentedControl](./segmented-control).

## Props

Dazu alle Attribute eines `<select>`. Die Möglichkeiten sind `<option>`-Kinder.

## Barrierefreiheit

- Ein echtes `<select>`: Tastatur, Screenreader und Auswahlfenster vom System.
- Label, Hinweis und Fehler wie beim [TextField](./text-field).
