# SearchField und SearchButton

`import { SearchField, SearchButton } from "@study/ui"`

**SearchField** filtert beim Tippen, z. B. Dateien eines Fachs. **SearchButton** sieht genauso aus, öffnet aber eine Suche woanders – in der App die Befehlspalette (⌘K).

```jsx live
function Beispiel() {
  const [q, setQ] = useState("");
  const files = ["Skript Kapitel 4", "Übungsblatt 5", "Formelsammlung Laplace"];
  return (
    <div className="ui-stack" style={{ maxWidth: 420 }}>
      <SearchButton label="Suchen oder anlegen" shortcut="⌘K" onOpen={() => toast("Hier öffnet sich die Befehlspalette")} />
      <SearchField label="Dokumente durchsuchen" value={q} onChange={(e) => setQ(e.target.value)} onClear={() => setQ("")} />
      <ul>{files.filter((f) => f.toLowerCase().includes(q.toLowerCase())).map((f) => <li key={f}>{f}</li>)}</ul>
      <Toaster />
    </div>
  );
}
```

## Barrierefreiheit

- Das Feld liegt in einem `role="search"`-Bereich und hat ein Label (für das Auge versteckt).
- Der Leeren-Knopf heißt „Suche leeren“.
- `SearchButton` gibt das Kürzel als `aria-keyshortcuts` an.
