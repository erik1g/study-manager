# FileDrop

`import { FileDrop } from "@study/ui"`

```jsx live
function Beispiel() {
  const [names, setNames] = useState([]);
  return (
    <div className="ui-stack">
      <FileDrop label="Dateien hochladen" hint="Hierher ziehen oder klicken · PDF, Word, Bilder · bis 95 MB" accept=".pdf,.docx,image/*" onFiles={(files) => setNames(files.map((f) => f.name))} />
      {names.length > 0 && <p>Gewählt: {names.join(", ")}</p>}
    </div>
  );
}
```

## Wann benutzen

- Wo Hochladen **die** Aufgabe ist: der Reiter Dokumente, ein leerer Ordner.
- Sonst reicht ein [Button](../aktionen/button) „Hochladen“ mit Icon `upload`, der ein Dateifenster öffnet.
- Der Hinweis nennt Art und Größe – die Grenze von 95 MB pro Datei soll niemand erst beim Fehler erfahren.
