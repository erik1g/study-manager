# Checkbox

`import { Checkbox } from "@study/ui"`

Die runde Box zum Abhaken. Mit `strike` wird eine erledigte Aufgabe durchgestrichen.

```jsx live
function Beispiel() {
  const [tasks, setTasks] = useState([
    { title: "Skript Kapitel 3 lesen", done: true },
    { title: "Übungsblatt 4 rechnen", done: false },
  ]);
  return (
    <div>
      {tasks.map((t, i) => (
        <Checkbox key={t.title} label={t.title} strike checked={t.done} tone="gruen"
          onChange={() => setTasks(tasks.map((x, j) => (j === i ? { ...x, done: !x.done } : x)))} />
      ))}
    </div>
  );
}
```

## Barrierefreiheit

- Ein echtes Kontrollkästchen unter der Box: Leertaste hakt an, Screenreader sagen „angehakt“.
- Die ganze Zeile ist anklickbar und mindestens 44 px hoch.
