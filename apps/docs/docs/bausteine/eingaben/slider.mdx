# Slider

`import { Slider } from "@study/ui"`

```jsx live
function Beispiel() {
  const [zoom, setZoom] = useState(1.5);
  return (
    <div style={{ maxWidth: 360 }}>
      <Slider label="Zoom" min={1} max={4} step={0.01} value={zoom} onChange={setZoom} format={(v) => `${v.toFixed(1)} ×`} />
    </div>
  );
}
```

## Wann benutzen

- Für Werte, bei denen das Gefühl zählt, nicht die genaue Zahl: Zoom eines Bilds, Lautstärke.
- Genaue Zahlen (Semester, Minuten): `TextField type="number"` oder `Select`.
