# TextField und TextArea

`import { TextField, TextArea } from "@study/ui"`

Ein Feld mit **Label darüber**, optional einem Hinweis darunter und einem Fehler, wenn etwas nicht passt.

```jsx live
function Beispiel() {
  const [title, setTitle] = useState("");
  return (
    <div className="ui-stack" style={{ maxWidth: 420 }}>
      <TextField
        label="Titel der Frist"
        placeholder="z. B. Abgabe Übungsblatt 5"
        value={title}
        onChange={(e) => setTitle(e.target.value)}
        error={title.length > 60 ? "Höchstens 60 Zeichen." : undefined}
        hint="Steht so im Kalender und auf Heute."
      />
      <TextArea label="Notiz" placeholder="Was du dir merken willst …" />
    </div>
  );
}
```

## Wann benutzen

<DoDont>
  <Do caption="Das Label sagt, was hineingehört; der Platzhalter zeigt ein Beispiel.">
    <TextField label="Fachname" placeholder="z. B. Regelungstechnik" />
  </Do>
  <Dont caption="Nur ein Platzhalter als Label – er verschwindet beim Tippen.">
    <TextField label="Fachname" hideLabel placeholder="Fachname" />
  </Dont>
</DoDont>

- `hideLabel` nur, wenn der Zweck ringsum eindeutig ist (z. B. die Zeile „Aufgabe hinzufügen“ in einer Liste).
- Fehler erst zeigen, wenn jemand das Feld verlassen oder abgeschickt hat – nicht beim ersten Tastendruck.
- Für Suchen [SearchField](./search-field), für Auswahl aus einer Liste [Select](./select).
- `TextArea` wächst mit dem Inhalt bis zur halben Fensterhöhe.

## Barrierefreiheit

- Label, Hinweis und Fehler sind über `for`, `aria-describedby` und `aria-invalid` mit dem Feld verbunden.
- Text in Feldern ist 16 px – so zoomt das iPhone nicht.
- Fehler stehen als Text da, nicht nur als roter Rahmen.
