# Tabs

`import { Tabs } from "@study/ui"`

```jsx live
function Beispiel() {
  const [tab, setTab] = useState("ueberblick");
  return (
    <Tabs
      label="Bereiche des Fachs"
      active={tab}
      onSelect={setTab}
      items={[
        { id: "ueberblick", label: "Überblick" },
        { id: "dokumente", label: "Dokumente" },
        { id: "notizen", label: "Notizen" },
        { id: "vorlesungen", label: "Vorlesungen" },
        { id: "lernkarten", label: "Lernkarten", count: 11 },
      ]}
      trailing={<IconButton icon="more" label="Weitere Bereiche" />}
    />
  );
}
```

In der App sind die Reiter Links, damit jeder Bereich eine eigene Adresse hat:

```tsx
<Tabs label="Bereiche des Fachs" active={tab} linkAs={Link}
  items={MAIN_TABS.map((t) => ({ id: t, label: de.tabs[t], href: `/faecher/${id}/${t}` }))} />
```

## Wann benutzen

- Für Bereiche **einer** Sache (eines Fachs, der Einstellungen) – nicht für die Hauptnavigation.
- Höchstens sechs sichtbar; seltene hinter einem `IconButton` ⋯ als `trailing`.
- Zum Auswählen eines Werts: [SegmentedControl](../eingaben/segmented-control).
