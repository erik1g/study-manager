## Wann benutzen

- Über dem Titel tieferer Seiten (Fach, Datei, Einstellungen › Sicherheit).
- Nicht auf den Hauptorten – dort sagt die Navigation genug.

## Barrierefreiheit

- Eine `nav` „Pfad“; der letzte Eintrag ist die aktuelle Seite (`aria-current="page"`), kein Link.
- Die Trenner ›  sind für Screenreader versteckt.
