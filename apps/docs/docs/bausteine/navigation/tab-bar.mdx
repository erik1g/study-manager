# TabBar

`import { TabBar } from "@study/ui"`

```jsx live
<div style={{ maxWidth: 390, padding: 12, background: "var(--ui-sunken)", borderRadius: 32 }}>
  <TabBar
    fixed={false}
    active="heute"
    items={[
      { id: "heute", label: "Heute", icon: "sun", href: "#" },
      { id: "faecher", label: "Fächer", icon: "grid", href: "#" },
      { id: "kalender", label: "Kalender", icon: "calendar", href: "#" },
      { id: "suchen", label: "Suchen", icon: "search", href: "#" },
    ]}
    action={{ label: "Neu anlegen", icon: "plus", onClick: () => toast("Neu …") }}
  />
  <Toaster />
</div>
```

## Wann benutzen

- Nur unter etwa 900 px Breite; darüber die [Sidebar](./sidebar).
- Vier Orte, in der Mitte höchstens eine runde Aktion („Neu“).
- Mit `fixed` (Standard) klebt sie unten und lässt Platz für den Home-Balken des iPhones. Der Inhalt darüber braucht unten etwa 100 px Abstand.
