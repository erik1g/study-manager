# Reverse proxy

The `web` container speaks **HTTP on port 8080** (see `HTTP_PORT`). Your reverse proxy accepts requests to your domain with **HTTPS** and forwards **everything** to this port: the web app, `/api`, `/mcp`, `/ical` and `/auth`. Study Manager needs no special path rules.

Important for every proxy:

- Pass on the **Host header** and **`X-Forwarded-For`**. The app limits requests per visitor.
- **Upload size**: documents can be large. Allow at least **100 MB** per request (the app uploads files one by one).
- **HTTPS is required**: passkeys and Claude's sign-in (OAuth) only work over it.
- If the proxy runs on **another machine**, set `BIND_ADDRESS=0.0.0.0` and protect the port with a firewall so that only the proxy reaches it. Enter the proxy's address in `TRUSTED_PROXIES` if it is not in a private network.

## Caddy

The easiest way if you have no proxy: Caddy gets the certificate itself.

```caddyfile
study.example.org {
	request_body {
		max_size 100MB
	}
	reverse_proxy 127.0.0.1:8080
}
```

## Nginx Proxy Manager

1. *Proxy Hosts → Add Proxy Host*: domain `study.example.org`, scheme `http`, forward to `<IP of the server>` port `8080`, **Websockets Support** on.
2. Tab *SSL*: request a Let's Encrypt certificate, *Force SSL* on.
3. Tab *Advanced*: `client_max_body_size 100m;`

## Traefik

Attach the `web` container to your Traefik with labels. In a `docker-compose.override.yml` next to the `docker-compose.yml`:

```yaml
services:
  web:
    ports: !reset []
    networks: [default, traefik]
    labels:
      - traefik.enable=true
      - traefik.docker.network=traefik
      - traefik.http.routers.study.rule=Host(`study.example.org`)
      - traefik.http.routers.study.entrypoints=websecure
      - traefik.http.routers.study.tls.certresolver=letsencrypt
      - traefik.http.services.study.loadbalancer.server.port=80

networks:
  traefik:
    external: true
```

Adjust the names of network, entrypoint and resolver to your Traefik.

## Cloudflare Tunnel

A tunnel needs no open port. Point it to the host port:

```yaml
# config.yml of cloudflared
ingress:
  - hostname: study.example.org
    service: http://localhost:8080
  - service: http_status:404
```

Note: Cloudflare lets through at most **100 MB** per request (on the free plan); larger files cannot be uploaded then. The app sends files one by one. You can additionally put **Cloudflare Access** in front of `/admin` and `/api/admin`; then the admin area is only reachable with a second check. That is optional; the app requires a passkey or authenticator app for admins anyway.

## Checking

```sh
curl -I https://study.example.org/api/health
```

must return `200`. If the sign-in shows an error, `SITE_URL` and `API_EXTERNAL_URL` in the `.env` usually do not match the address you use in the browser.
