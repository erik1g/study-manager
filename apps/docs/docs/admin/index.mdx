# Overview for admins

Study Manager runs at your place: on a small server, a Raspberry Pi or a computer at home. This guide is for students who **know their way around Docker and a reverse proxy** (or want to learn it).

## What you need

- A **Linux server** (or Mac/Windows with Docker) with **Docker Compose**. 2 GB of memory and a few GB of disk are enough for a study group; documents and backups need space depending on how many there are.
- A **domain** (or subdomain) that points to the server or your tunnel.
- A **reverse proxy with HTTPS** in front (Nginx Proxy Manager, Traefik, Caddy, Cloudflare Tunnel …). The app only speaks unencrypted HTTP on port 80; TLS ends at your proxy. This is necessary because passkeys and Claude's sign-in (OAuth) require HTTPS.
- Optional: an **SMTP account** for invitation and password mails. Without it you pass on links by hand.

## What the app consists of

Four containers in one Docker Compose project:

| Container | Job |
|---|---|
| `web` | Caddy with the built web app; the **one address** your proxy points to. Passes `/api`, `/mcp`, `/ical` and `/auth` on to the others. |
| `server` | API, MCP server and background jobs (calendar subscriptions, search, backups) |
| `auth` | Sign-in, passkeys and OAuth (Supabase Auth / GoTrue) |
| `db` | PostgreSQL 17 |

The images come from Docker Hub (`erik1g/study-manager-server`, `erik1g/study-manager-web`); database and sign-in use the images from Supabase. Everything runs at your place – none of it goes to Supabase or to us.
