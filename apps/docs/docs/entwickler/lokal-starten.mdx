# Lokal starten

## Voraussetzungen

- **Docker** mit Compose
- **Node.js 24** und **pnpm 12** (`npm install -g pnpm@12.16.1`)

## Schritte

```sh
git clone https://github.com/erik1g/study-manager.git
cd study-manager
pnpm install
ADMIN_EMAIL=du@example.org DOMAIN=localhost node infra/scripts/setup.mjs   # schreibt .env
docker compose -f docker-compose.dev.yml up -d
docker compose -f docker-compose.dev.yml logs server   # der Link zum Einrichten des Admin-Kontos
```

Der Entwicklungsstack (`docker-compose.dev.yml`) hängt den Quellcode in die Container ein: **Server und Web-App laden bei Änderungen neu**. Die App erreichst du unter `http://localhost:8080`.

Zum Anmelden mit einem Testkonto nimmst du statt dessen den **Test-Stack** (siehe [Tests](/entwickler/tests)): Er hat erfundene Daten und feste Konten.

## Alltag

```sh
pnpm typecheck          # TypeScript aller Pakete
pnpm test               # Unit-Tests (Server braucht die Datenbank des Entwicklungsstacks)
node infra/scripts/ui-gate.mjs   # prüft: nur Bausteine aus @study/ui
pnpm --filter @study/docs start  # diese Doku lokal (Port 3002)
```

## Server-Tests

Die Tests des Servers laufen gegen eine echte PostgreSQL-Datenbank:

```sh
docker compose -f docker-compose.dev.yml exec server sh -c "cd apps/server && pnpm exec vitest run"
```

## Probleme

- **Berechtigungen auf `.pnpm-store`**: Das Projekt nutzt einen Paketspeicher im Repository, den die Dev-Container mitbenutzen. Lösche den Ordner und starte `pnpm install` neu.
- **Port 8080 belegt**: Setze `HTTP_PORT` in der `.env`.
