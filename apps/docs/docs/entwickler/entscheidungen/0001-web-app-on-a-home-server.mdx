# A web app on a home server replaces the synced desktop app

The desktop app kept its data in files and synced them with Google Drive, deadlines with iCloud and tasks with Notion. Each sync worked, but together they were hard to oversee, and nothing could be shared with fellow students. The Study Manager is now one web application with one database, run on a server of one's own (at home or rented) behind a reverse proxy; phones get a read-only calendar subscription, and Google Drive only receives backups.

The cloud runs no AI of its own. Every user connects their own Claude through the MCP server, so there are no API costs to share and no keys to hold; what the desktop app did automatically (evaluating lectures, outlining scripts) becomes work Claude does when asked. Transcription runs in the user's browser.

Subjects are shared with roles (owner, editor, viewer). Tasks, private notes and learning progress stay with each user. The stack is TypeScript throughout (Fastify, Drizzle, React) on a self-hosted Supabase for Postgres and sign-in, because Supabase Auth brings passkeys and an OAuth 2.1 server for MCP clients. Rewriting the Rust logic was cheaper than it looked, as most of it dealt with the syncs that went away.
