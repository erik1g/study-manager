# Slider

`import { Slider } from "@study/ui"`

```jsx live
function Example() {
  const [zoom, setZoom] = useState(1.5);
  return (
    <div style={{ maxWidth: 360 }}>
      <Slider label="Zoom" min={1} max={4} step={0.01} value={zoom} onChange={setZoom} format={(v) => `${v.toFixed(1)} ×`} />
    </div>
  );
}
```

## When to use

- For values where the feel counts, not the exact number: zoom of a picture, volume.
- Exact numbers (semester, minutes): `TextField type="number"` or `Select`.

## Accessibility

- A real `<input type="range">`: arrow keys change the value, screen readers read it out.
