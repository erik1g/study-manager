# TextField and TextArea

`import { TextField, TextArea } from "@study/ui"`

A field with a **label above it**, optionally a hint below it and an error when something does not fit.

```jsx live
function Example() {
  const [title, setTitle] = useState("");
  return (
    <div className="ui-stack" style={{ maxWidth: 420 }}>
      <TextField
        label="Deadline title"
        placeholder="e.g. Submit exercise sheet 5"
        value={title}
        onChange={(e) => setTitle(e.target.value)}
        error={title.length > 60 ? "At most 60 characters." : undefined}
        hint="Shown like this in the calendar and on Today."
      />
      <TextArea label="Note" placeholder="What you want to remember …" />
    </div>
  );
}
```

## When to use

<DoDont>
  <Do caption="The label says what goes in; the placeholder shows an example.">
    <TextField label="Course name" placeholder="e.g. Control Engineering" />
  </Do>
  <Dont caption="Only a placeholder as a label – it disappears while typing.">
    <TextField label="Course name" hideLabel placeholder="Course name" />
  </Dont>
</DoDont>

- `hideLabel` only when the purpose is clear from the surroundings (e.g. the "Add task" row in a list).
- Show errors only once someone has left the field or submitted – not on the first key press.
- For searches [SearchField](./search-field), for choosing from a list [Select](./select).
- `TextArea` grows with its content up to half the window height.

## Accessibility

- Label, hint and error are connected to the field through `for`, `aria-describedby` and `aria-invalid`.
- Text in fields is 16 px – so the iPhone does not zoom.
- Errors are there as text, not only as a red border.
