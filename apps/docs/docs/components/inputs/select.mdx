# Select

`import { Select } from "@study/ui"`

A choice with the system's picker – the wheel on phones, the list on computers.

```jsx live
<div style={{ maxWidth: 360 }}>
  <Select label="Folder" defaultValue="scripts" hint="Where the file goes.">
    <option value="scripts">Scripts</option>
    <option value="exercises">Exercises</option>
    <option value="exams">Past exams</option>
    <option value="other">Other</option>
  </Select>
</div>
```

## When to use

<DoDont>
  <Do caption="Many options, one of them applies.">
    <Select label="Course"><option>Control Engineering</option><option>Maths III</option></Select>

  <Dont caption="Two to four options – they belong visibly side by side.">
    <Select label="Appearance"><option>Light</option><option>Dark</option></Select>
  </Dont>
</DoDont>
