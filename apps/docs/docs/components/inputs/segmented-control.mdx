# SegmentedControl

`import { SegmentedControl } from "@study/ui"`

```jsx live
function Example() {
  const [theme, setTheme] = useState("system");
  return (
    <SegmentedControl
      label="Appearance"
      value={theme}
      onChange={setTheme}
      options={[
        { value: "light", label: "Light", icon: "sun" },
        { value: "dark", label: "Dark", icon: "star" },
        { value: "system", label: "System", icon: "settings" },
      ]}
    />
  );
}
```

## When to use

<DoDont>
  <Do caption="Few options, all visible, one applies.">
    <SegmentedControl label="View" value="week" onChange={() => {}} options={[{ value: "day", label: "Day" }, { value: "week", label: "Week" }]} />
  </Do>
  <Dont caption="More than four – then a Select.">
    <SegmentedControl label="Course" size="sm" value="a" onChange={() => {}} options={["CE", "EM", "MS", "M3", "TD", "CL"].map((x) => ({ value: x.toLowerCase(), label: x }))} />
  </Dont>
</DoDont>

For switching between areas of a page there are [Tabs](../navigation/tabs).

## Accessibility

- Real radio buttons in a `radiogroup`: arrow keys switch, Tab jumps in and out.
- With `iconsOnly`, the names remain for screen readers and as a tooltip.
