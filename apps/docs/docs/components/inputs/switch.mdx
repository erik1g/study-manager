# Switch

`import { Switch } from "@study/ui"`

```jsx live
function Example() {
  const [on, setOn] = useState(true);
  return (
    <div style={{ maxWidth: 420 }}>
      <Switch label="Reminders by email" description="One day before every deadline." checked={on} onChange={(e) => setOn(e.target.checked)} />
    </div>
  );
}
```

## Accessibility

- A checkbox with `role="switch"`: screen readers say "on" or "off".
- Green means on – and the knob is on the right. Both together, not the colour alone.
