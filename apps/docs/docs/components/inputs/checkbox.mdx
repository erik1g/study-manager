# Checkbox

`import { Checkbox } from "@study/ui"`

The round box for ticking off. With `strike`, a finished task is crossed out.

```jsx live
function Example() {
  const [tasks, setTasks] = useState([
    { title: "Read script chapter 3", done: true },
    { title: "Do exercise sheet 4", done: false },
  ]);
  return (
    <div>
      {tasks.map((t, i) => (
        <Checkbox key={t.title} label={t.title} strike checked={t.done} tone="gruen"
          onChange={() => setTasks(tasks.map((x, j) => (j === i ? { ...x, done: !x.done } : x)))} />
      ))}
    </div>
  );
}
```

- A real checkbox under the box: Space ticks it, screen readers say "checked".
- The whole row is clickable and at least 44 px high.
