# Spinner

`import { Spinner } from "@study/ui"`

```jsx live
<div style={{ display: "flex", gap: 16, alignItems: "center" }}>
  <Spinner />
  <Spinner size={32} />
  <span style={{ display: "inline-flex", gap: 8, alignItems: "center", color: "var(--ui-muted)" }}>
    <Spinner size={16} label="" /> Transcribing …
  </span>
</div>
```

## When to use

- For waits of unknown length that last longer than a moment.
- Do not build it into buttons yourself – `loading` on the [Button](../actions/button).
- Whole pages: `PageSkeleton`. Known progress: [ProgressRing](../display/progress-ring).

## Accessibility

- With a `label` it is a `status` ("Lädt" by default); if the text stands next to it, use `label=""`.
