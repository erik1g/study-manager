## When to use

- Above the title of deeper pages (course, file, Settings › Security).
- Not on the main places – the navigation says enough there.

## Accessibility

- A `nav` "Pfad" (path); the last entry is the current page (`aria-current="page"`), not a link.
- The separators › are hidden from screen readers.
