# Tabs

`import { Tabs } from "@study/ui"`

```jsx live
function Example() {
  const [tab, setTab] = useState("overview");
  return (
    <Tabs
      label="Areas of the course"
      active={tab}
      onSelect={setTab}
      items={[
        { id: "overview", label: "Overview" },
        { id: "documents", label: "Documents" },
        { id: "notes", label: "Notes" },
        { id: "lectures", label: "Lectures" },
        { id: "flashcards", label: "Flashcards", count: 11 },
      ]}
      trailing={<IconButton icon="more" label="More areas" />}
    />
  );
}
```

In the app the tabs are links, so that every area has its own address:

```tsx
<Tabs label="Bereiche des Fachs" active={tab} linkAs={Link}
  items={MAIN_TABS.map((t) => ({ id: t, label: de.tabs[t], href: `/faecher/${id}/${t}` }))} />
```

## When to use

- For areas of **one** thing (a course, the settings) – not for the main navigation.
- At most six visible; rare ones behind an `IconButton` ⋯ as `trailing`.
- For choosing a value: [SegmentedControl](../inputs/segmented-control).

## Accessibility

- A `nav` with a name; the active tab is `aria-current`.
- Links stay links (Ctrl-click, back button); buttons stay buttons.
