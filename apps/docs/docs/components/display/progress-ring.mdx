# ProgressRing

`import { ProgressRing } from "@study/ui"`

```jsx live
function Example() {
  const [v, setV] = useState(0.62);
  return (
    <div style={{ display: "flex", gap: 20, alignItems: "center" }}>
      <ProgressRing value={v} label={`${Math.round(v * 100)} percent done`} size={104} thickness={12} tone="petrol">
        <span style={{ fontSize: 24 }}>{Math.round(v * 100)} %</span>
      </ProgressRing>
      <input type="range" min="0" max="1" step="0.01" value={v} onChange={(e) => setV(+e.target.value)} aria-label="Value" />
    </div>
  );
}
```

## When to use

- Progress of a course, a study session, an upload of known size.
- On course colours with `onTint` – then the track is white.
- `animateKey`: the ring runs up the first time it appears in a visit, afterwards it stands still.
- Unknown duration? Then [Spinner](../feedback/spinner).

## Accessibility

- An image with `label` as its description – say the number in words there ("8 of 13 chapters").
- The colour `strong` is light; so the number is always also there as text next to it or inside.
