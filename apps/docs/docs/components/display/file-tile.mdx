# FileTile

`import { FileTile, fileKind } from "@study/ui"`

```jsx live
<List style={{ maxWidth: 480 }}>
  {["Script chapter 4.pdf", "Formula sheet.docx", "Lecture 27 Oct.m4a", "Blackboard.jpg"].map((name) => (
    <ListRow key={name} leading={<FileTile kind={fileKind(name)} />} title={name} meta="Scripts · today" />
  ))}
</List>
```
