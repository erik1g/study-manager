# CountdownTile

`import { CountdownTile } from "@study/ui"`

```jsx live
<List variant="raised" style={{ maxWidth: 440 }}>
  <ListRow leading={<CountdownTile value={2} unit="days" tone="orange" />} title="Submit exercise sheet 4" meta="Engineering Mechanics · Thu, 5 Nov" />
  <ListRow leading={<CountdownTile value="Today" unit="23:59" tone="rot" />} title="Exam registration" meta="Examination office" />

```

## When to use

- In front of deadlines in lists. The colour is the course's – not "red because soon".
- Mind the singular: "1 day", "2 days". Today: `value="Today"` and the time as `unit`.
