# ProgressBar

`import { ProgressBar } from "@study/ui"`

```jsx live
function Example() {
  const [v, setV] = useState(0.35);
  return (
    <div className="ui-stack" style={{ maxWidth: 420 }}>
      <ProgressBar value={v} label="Transcribing" tone="violett" />
      <Button size="sm" onClick={() => setV(Math.min(1, v + 0.15))}>Next</Button>
    </div>
  );
}
```

## When to use

- For jobs with known progress that take seconds to minutes: uploading, transcribing.
- Progress of a course: [ProgressRing](./progress-ring). Unknown duration: [Spinner](../feedback/spinner).

## Accessibility

- `role="progressbar"` with a value of 0–100 and the label as its name; the value is also there as text.
