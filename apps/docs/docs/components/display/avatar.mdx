# Avatar and AvatarGroup

`import { Avatar, AvatarGroup } from "@study/ui"`

Without a picture, the avatar shows the initials in the person's colour – the same everywhere, because it is calculated from the id (`colorKey`).

```jsx live
<div style={{ display: "flex", gap: 16, alignItems: "center" }}>
  <Avatar name="Mira Hansen" size={48} />
  <AvatarGroup label="4 members">
    <Avatar name="Mira Hansen" colorKey="u1" decorative />
    <Avatar name="Jonas Weber" colorKey="u2" decorative />
    <Avatar name="Sina Ok" colorKey="u3" decorative />
    <Avatar name="Tom Berg" colorKey="u4" decorative />
  </AvatarGroup>
</div>
```

## When to use

- Next to a name: `decorative`, so that the name is not read out twice.
- In the app, the picture `src` from `/api/avatars/<id>?v=<version>` is enough; if it is missing or does not load, the initials appear.
- Deleted accounts: `gone` – grey with a line.
