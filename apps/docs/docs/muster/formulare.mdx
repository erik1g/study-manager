# Formulare

```jsx live
function Beispiel() {
  const [name, setName] = useState("");
  const [tried, setTried] = useState(false);
  const [saving, setSaving] = useState(false);
  const error = tried && !name.trim() ? "Gib dem Fach einen Namen." : undefined;
  return (
    <Card style={{ maxWidth: 480 }}>
      <form className="ui-stack" onSubmit={(e) => {
        e.preventDefault();
        setTried(true);
        if (!name.trim()) return;
        setSaving(true);
        setTimeout(() => { setSaving(false); toast("Fach angelegt", "success"); }, 900);
      }}>
        <SectionHeader title="Neues Fach" />
        <TextField label="Name" placeholder="z. B. Regelungstechnik" value={name} onChange={(e) => setName(e.target.value)} error={error} />
        <Select label="Semester" defaultValue="w"><option value="w">WiSe 26/27</option><option value="s">SoSe 27</option></Select>
        <Checkbox label="Mitstudierende einladen" description="Du bekommst danach einen Link zum Teilen." />
        <div style={{ display: "flex", gap: 10, justifyContent: "flex-end" }}>
          <Button>Abbrechen</Button>
          <Button type="submit" variant="primary" loading={saving}>Anlegen</Button>
        </div>
      </form>
      <Toaster />
    </Card>
  );
}
```

## Regeln

1. **Labels über den Feldern**, nie nur Platzhalter.
2. **Eine Spalte.** Felder untereinander, in der Reihenfolge, in der man denkt.
3. **Pflicht ist der Normalfall.** Kennzeichne die freiwilligen („optional“ im Hinweis), nicht die nötigen mit Sternchen.
4. **Fehler nach dem Absenden** oder beim Verlassen des Felds – am Feld, als ganzer Satz, der sagt, was zu tun ist.
5. **Ein Fehler vom Server** (z. B. keine Verbindung) erscheint als `Notice tone="danger"` über den Knöpfen; was eingegeben war, bleibt stehen.
6. **Knöpfe unten rechts**: Abbrechen, dann die Hauptaktion. Während des Speicherns `loading`.
7. Was sofort gilt, braucht keinen Speichern-Knopf: `Switch`, `SegmentedControl`.
