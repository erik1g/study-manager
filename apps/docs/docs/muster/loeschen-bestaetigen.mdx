# Löschen bestätigen

| Was | Wie |
| --- | --- |
| Dateien, Karten, Aufnahmen | **ohne** Rückfrage in den Papierkorb, dazu ein Toast „In den Papierkorb gelegt“ |
| Endgültig aus dem Papierkorb | `ConfirmDialog` |
| Ein ganzes Fach, ein Mitglied entfernen, ein Fach verlassen | `ConfirmDialog` mit `danger` |
| Das eigene Konto | eigene Seite: E-Mail-Adresse zur Bestätigung eintippen |

```jsx live
function Beispiel() {
  const [ask, setAsk] = useState(false);
  return (
    <>
      <Button variant="danger" icon="logout" onClick={() => setAsk(true)}>Fach verlassen</Button>
      {ask && (
        <ConfirmDialog title="Regelungstechnik verlassen?" confirm="Verlassen" danger onClose={() => setAsk(false)} onConfirm={() => toast("Du hast das Fach verlassen")}>
          Du siehst seine Dateien und Notizen dann nicht mehr. Ein Mitglied kann dich wieder einladen.
        </ConfirmDialog>
      )}
      <Toaster />
    </>
  );
}
```

## Regeln

- Der Titel ist eine Frage mit dem **Namen** dessen, was verschwindet.
- Der Text sagt, was danach ist, und ob es zurückkommt.
- Der Knopf wiederholt das Verb: „Löschen“, „Verlassen“, „Entfernen“ – nie „Ja“.
- „Abbrechen“ hat den Fokus.
