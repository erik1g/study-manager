# Leere Zustände

Leer ist kein Fehler, sondern ein Anfang. Ein leerer Zustand sagt **was hier hinkommt** und bietet **den ersten Schritt**.

| Wo | Szene | Titel | Aktion |
| --- | --- | --- | --- |
| Keine Fächer | `buecher` | Noch keine Fächer | Fach anlegen |
| Keine Dateien | `buecher` | Noch keine Dateien | Hochladen |
| Keine Lernkarten | `karten` | Noch keine Lernkarten | Stapel anlegen · Mit Claude erstellen |
| Keine Notizen | `pflanze` | Noch keine Notizen | Schreiben |
| Heute nichts | `tasse` | Heute ist frei | – |
| Alles erledigt | `fertig` | Alles erledigt | – |
| Keine Treffer | `suche` | Keine Treffer für „…“ | Suche leeren |
| Papierkorb leer | – (klein) | Der Papierkorb ist leer | – |

```jsx live
<div style={{ display: "grid", gap: 16, gridTemplateColumns: "repeat(auto-fit, minmax(260px, 1fr))" }}>
  <EmptyState size="sm" illustration="tasse" title="Heute ist frei">Keine Termine und nichts fällig. Genieß es.</EmptyState>
  <EmptyState size="sm" illustration="suche" variant="plain" title="Keine Treffer für „Laplas“" actions={<Button size="sm">Suche leeren</Button>}>Vielleicht „Laplace“?</EmptyState>
</div>
```

## Regeln

- Leser (Rolle „Leser“) sehen keine Aktion, die sie nicht ausführen dürfen – nur den Text.
- In kleinen Bereichen (eine Karte auf Heute) reicht ein Satz ohne Illustration.
- Nie „Keine Daten“ oder „Nichts gefunden“ ohne Zusammenhang.
