Study Manager is free software under the [GPL-3.0](https://github.com/erik1g/study-manager/blob/main/LICENSE). You run it yourself on your own server – your data stays with you and your study group.

## Where would you like to start?

### I want to use it → [Users](/users)

Courses, documents, deadlines, planning, notes, lecture mode, flashcards and connecting Claude.

### I run a server → [Admin](/admin)

Install with Docker, configure, put it behind a reverse proxy, back up, update.

### I want to develop along → [Developers](/developers)

Structure, running locally, tests, contributions, releases – and how to connect a new university.

## What is supported today

- The interface speaks **English and German**; everyone chooses their own. Semesters are stored as `WiSe`/`SoSe` (winter/summer term) and shown as "Winter semester 2026/27".
- The **calendar subscription** understands iCal feeds in the style of CAMPUSonline (timetable with series and sessions). Other systems (Stud.IP, HISinOne, ILIAS) are not connected yet – **you can help with that**: see [Connecting universities](/developers/connecting-universities).
- Everything else is independent of the university: courses, documents, deadlines, tasks, notes, flashcards, search, module handbook (as a PDF) and the connection to Claude.
