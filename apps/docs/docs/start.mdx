Der Study Manager ist freie Software unter der [GPL-3.0](https://github.com/erik1g/study-manager/blob/main/LICENSE). Du betreibst ihn selbst auf einem eigenen Server – deine Daten bleiben bei dir und deiner Lerngruppe.

## Wo möchtest du anfangen?

### Ich möchte ihn benutzen → [Nutzer](/nutzer)

Fächer, Dokumente, Deadlines, Planung, Notizen, Vorlesungsmodus, Lernkarten und Claude verbinden.

### Ich betreibe einen Server → [Admin](/admin)

Installieren mit Docker, konfigurieren, hinter einen Reverse Proxy stellen, sichern, aktualisieren.

### Ich möchte mitentwickeln → [Entwickler](/entwickler)

Aufbau, lokal starten, Tests, Beiträge, Releases – und wie man eine neue Hochschule anbindet.

## Was heute unterstützt wird

- Die Oberfläche ist **deutsch**; Semester heißen `WiSe`/`SoSe`.
- Das **Kalender-Abo** versteht iCal-Feeds im Stil von CAMPUSonline (Stundenplan mit Serien und Sitzungen). Andere Systeme (Stud.IP, HISinOne, ILIAS) sind noch nicht angebunden – **dabei kannst du helfen**: siehe [Hochschulen anbinden](/entwickler/hochschulen-anbinden).
- Alles andere ist hochschulunabhängig: Fächer, Dokumente, Deadlines, Aufgaben, Notizen, Lernkarten, Suche, Modulhandbuch (als PDF) und die Anbindung an Claude.
