# Deadlines und Aufgaben

Es gibt zwei verschiedene Dinge:

- **Deadline**: ein Zeitpunkt wie eine Klausur oder eine Abgabe. **Mit Fach** ist sie für alle Mitglieder sichtbar, **ohne Fach** nur für dich.
- **Aufgabe**: ein To-do von dir. Aufgaben sind **immer privat**, geplant für einen Tag und optional eine Uhrzeit; mit Uhrzeit blockt eine Aufgabe ihre geschätzte Dauer als **Zeitblock** im Kalender.

## Wer darf was bei einer geteilten Deadline

| Aktion | Besitzer | Bearbeiter | Leser |
|---|---|---|---|
| **Anlegen** (mit Fach) | ✓ | ✓ | – |
| **Ändern** (Titel, Zeit, Notiz, Fach) | ✓ | ✓ | – |
| **Löschen** | ✓ | ✓ | – |
| **Abhaken** | ✓ für sich | ✓ für sich | ✓ für sich |
| **Private Deadline** (ohne Fach) anlegen, ändern, löschen | ✓ | ✓ | ✓ |

Wichtig:

- **Jeder Bearbeiter und Besitzer** darf jede geteilte Deadline des Fachs ändern oder löschen – egal, wer sie angelegt hat. Das passt zu einer Lerngruppe, in der Vertrauen herrscht: Ein falscher Termin lässt sich sofort korrigieren.
- **Abhaken ist persönlich.** Du hakst eine Deadline nur für dich ab; bei den anderen ändert sich nichts. Abgehakte und vergangene Deadlines bleiben unter *Erledigt und vorbei* sichtbar.
- **Leser** sehen geteilte Deadlines und haken sie für sich ab, ändern sie aber nicht (das ⋯-Menü fehlt dann). Brauchst du als Leser eine Änderung, bitte einen Bearbeiter oder den Besitzer, dich zum Bearbeiter zu machen.
- **Nachvollziehbar:** Das Anlegen, Ändern und Löschen steht im *Aktivitäts*-Verlauf des Fachs, mit Namen.

## Wo du sie bearbeitest

Überall, wo eine Deadline als Zeile erscheint (*Heute*, *Todos*, *Fach → Überblick*), steht ein ⋯-Menü mit **Bearbeiten** und **Löschen**. Im **Kalender** öffnet ein Klick auf eine Deadline einen Dialog mit **Bearbeiten**, **Löschen** und **Erledigt**; die Zeit änderst du auch durch Ziehen.
