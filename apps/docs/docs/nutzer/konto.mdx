# Konto und Einstellungen

Unter *Einstellungen* (links unten am Konto) findest du:

| Seite | Was |
|---|---|
| **Profil** | Anzeigename, Foto, Uni und Studiengang (frei), Fachsemester |
| **Darstellung** | Hell, Dunkel oder wie das System |
| **Sicherheit** | Passwort, **Passkeys** und **Authenticator-App** als zweiter Faktor |
| **Studiengang** | Studiengänge und Modulkataloge |
| **Kalender** | Stundenplan-Abos und dein privater Abo-Link |
| **Transkription** | Wie Vorlesungen transkribiert werden (im Browser oder mit eigenem Schlüssel) |
| **Claude** | Verbindungen und Schlüssel für dein Claude |

**Konto löschen**: Unter *Profil* kannst du dein Konto löschen. Geteilte Fächer bleiben bei den anderen Mitgliedern bestehen. Bist du der einzige Admin, mache zuerst jemand anderen zum Admin.
