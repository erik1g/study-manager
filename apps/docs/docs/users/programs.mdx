# Programmes and module handbook

A **programme** belongs to a university and has exactly one **module catalogue**, which everyone who studies it shares. You find the programmes under *Settings → Programme*.

## Creating a programme

Create it with university, name, degree and examination regulations. Whoever creates it is its **manager** – only they (or an admin) change the module catalogue. Then you upload the **module handbook as a PDF**.

## Reading in modules

Your Claude does the reading: it reads the handbook section by section and enters the modules (number, title, credits and the other details from the handbook). It only takes what is in the handbook. This is how you tell it: *"Import the module handbook of my programme."*

## Courses from modules

In the module list, a click opens the module's details. There you create a course for the current semester with **Create course**; it takes over number, title and credits. You can **enrol** in a programme so that it shows up for you.
