# Deadlines and tasks

There are two different things:

- **Deadline**: a point in time such as an exam or a submission. **With a course** it is visible to all members, **without a course** only to you.
- **Task**: a to-do of yours. Tasks are **always private**, planned for a day and optionally a time; with a time, a task blocks its estimated duration as a **time block** in the calendar.

## Who may do what with a shared deadline

| Action | Owner | Editor | Reader |
|---|---|---|---|
| **Create** (with a course) | ✓ | ✓ | – |
| **Change** (title, time, note, course) | ✓ | ✓ | – |
| **Delete** | ✓ | ✓ | – |
| **Tick off** | ✓ for themselves | ✓ for themselves | ✓ for themselves |
| Create, change, delete a **private deadline** (without a course) | ✓ | ✓ | ✓ |

Important:

- **Every editor and owner** may change or delete every shared deadline of the course – no matter who created it. That suits a study group built on trust: a wrong date can be corrected at once.
- **Ticking off is personal.** You tick off a deadline only for yourself; nothing changes for the others. Ticked-off and past deadlines stay visible under *Done and past*.
- **Readers** see shared deadlines and tick them off for themselves, but do not change them (the ⋯ menu is missing then). If you need a change as a reader, ask an editor or the owner to make you an editor.
- **Traceable:** Creating, changing and deleting shows up in the course's *Activity* history, with names.

## Where you edit them

Wherever a deadline appears as a row (*Today*, *Todos*, *Course → Overview*), there is a ⋯ menu with **Edit** and **Delete**. In the **calendar**, a click on a deadline opens a dialog with **Edit**, **Delete** and **Done**; you can also change the time by dragging.
