# Notes and lecture mode

## Notes next to the script

In a course's **Notes** tab, the script (a PDF from the *Scripts* folder) is on the left and the notes are on the right.

- **Shared** are the course's notes that all editors write; **Private** are your own, which nobody else sees.
- **Read or write**: notes are Markdown with formulas in LaTeX (`$…$`). While you write, the app saves automatically; if two people write at the same time, it asks which version should count.
- **Language of the notes**: a course has a language – the one its creator used when they created it (also when Claude created it for them). The standard headings (*Exam-relevant*, *From the lecture, without a chapter*) and what Claude adds after a lecture are written in it, so the notes stay in one language for all members, whatever language each of them uses for the interface. Courses from before this setting existed are German. You cannot change the language of a course yet.
- **Follow along**: when the switch is on, the notes scroll to the section that belongs to the script page. Headings with a marker like `<!-- skript:… -->` connect note and page; a click on the heading jumps to the script page.

## Lecture mode

**Lecture mode** gives script and notes the **whole browser window**: without sidebar, header and tabs, only with a narrow bar at the top. You start it with the **Lecture mode** button in every document view and in the Notes tab.

- **Tabs**: You can have several documents and the notes open at once. With **＋** you open another document or the notes, with **×** you close a tab.
- **Side by side**: With *Side by side* you split the area into two halves, each with its own tab bar, for example the script on the left and the notes on the right. With the arrow (or a right-click on a tab) you move a tab to the other half. On small screens there is only one half.
- **Zoom**: minus, plus and the percentage (back to page width), as well as `Ctrl`/`⌘` + mouse wheel and pinch (two fingers). The zoom applies per tab and is remembered; for the notes it changes the font size.
- **Writing** works as usual: switch to *Write* in the notes tab.
- **Exit** with Esc or the × button at the top left. Your state (open tabs, split, zoom) stays saved per course in this browser, even after reloading.

On a phone the mode fills the whole screen, also over the tab bar.
