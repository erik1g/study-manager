# Schrift

Zwei Schriften, beide im Paket enthalten (über `@fontsource-variable`, ohne Google-Server):

- **Bricolage Grotesque**, 800 – Überschriften, große Zahlen, Uhrzeiten auf Karten. Kräftig und ein wenig verspielt.
- **Figtree**, 400–700 – aller Text, Knöpfe, Felder.

| Token | Wert |
| --- | --- |
| `--ui-font-display` | Bricolage Grotesque |
| `--ui-font-body` | Figtree |
| `--ui-font-mono` | Systemschrift für Code |

## Regeln

- Seitentitel: `SectionHeader size="xl"` (46 px, auf dem Handy kleiner). Kartentitel: `md` (22 px).
- Fließtext 15 px, zweite Zeilen 13 px in `--ui-muted`. Nichts unter 12 px.
- In Feldern 16 px – darunter zoomt Safari auf dem iPhone beim Antippen.
- Fett (700) für das, worum es in einer Zeile geht; nicht für ganze Absätze.
- Die Klasse `ui-display` gibt einem Element die Überschriftenschrift, wenn es kein Baustein ist.
