## Wofür welche

| Szene | Wofür |
| --- | --- |
| `schreibtisch` | Heute, Willkommen |
| `buecher` | Fächer, Fachseite, Anmeldung |
| `tasse` | Anmeldung, Pausen, „alles erledigt für heute“ |
| `kalender` | Kalender, keine Termine |
| `stern` | Erfolg, Lernserie |
| `karten` | Lernkarten |
| `fertig` | Aufgaben erledigt, Upload fertig |
| `pflanze` | leere Notizen, ruhige Zustände |
| `suche` | keine Treffer |
| `fehler` | etwas ging schief, Seite nicht gefunden |

## Regeln

- Eine Illustration pro Ansicht, nicht mehr. Sie schmückt, sie erklärt nicht – das tut der Text daneben.
- Nicht kleiner als 100 px Breite, sonst werden die Konturen zu dick.
