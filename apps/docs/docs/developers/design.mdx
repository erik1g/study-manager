# Design system "Snug Simple"

The app's interface is made of the building blocks in `packages/ui`: a warm background, eight pastel colours for the courses, round shapes and illustrations of its own. The pages of this documentation show **every component for real** with the code that runs in the app.

- [Getting started and the one rule](/design)
- **Foundations**: colours, typography, spacing, shadows and motion, icons, illustrations
- **Components**: actions, inputs, display, navigation, feedback
- **Patterns**: forms, lists with actions, confirming deletion, empty states, error messages
- [Voice and tone](/voice-and-tone)
- [Creating or changing a component](/design-system-contributing)
